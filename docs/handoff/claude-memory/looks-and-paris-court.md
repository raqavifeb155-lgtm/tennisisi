2026-10-06 в игру добавлены: `scripts/looks.gd` (палитры и словарь внешности), `scripts/look_editor.gd` (экран «ИГРОК → ВНЕШНОСТЬ»), внешность в `Athlete.set_look()`, `SaveData.look` (секция `player`), `"look"` у соперников в `opponents.gd`, локация `paris` (`scripts/scenery_chatrier.gd`). **Why:** пользователь хочет создавать своего персонажа и большую выборку игроков (см. [[top100-roster-research]]), плюс корт по мотивам Филипп-Шатрие для будущего «легендарного матча» (финал RG-2025, старт с 3–5, 0–40 на подаче Алькараса).

**How to apply:**
- Проект закреплён на Godot 4.4.1 (`tools/build_web.sh`). Локально установлен только 4.7.1 (архив в Downloads), поэтому проверки шли на копии проекта во временной папке, а не в рабочем проекте: 4.7 переписывает служебные файлы.
- Веб-сборку `build/web` после этих правок нужно пересобрать: шаблонов экспорта на этом ПК нет.
- Переход на 4.7: сначала сравнить производительность с 4.4.1 тем же замером и проверить формулу пути сохранений в вебе (`custom_user_dir_name`), иначе игроки могут потерять прогресс.
- Левша не сделан: весь риг считается «вправо».
- Второе окно параллельно готовит патч геймплея (`docs/superpowers/specs/2026-10-06-gameplay-patch-design.md`), он трогает `athlete.gd`, `main.gd`, `opponents.gd`. Git в проекте нет, резервная копия лежит в `work/backup-tennis-2026-10-05-2355`.
