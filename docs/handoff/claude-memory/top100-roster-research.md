Ресерч топ-100 ATP (рейтинг от 28.09.2026) лежит в `work/tennis/docs/roster/` (`TOP100_RESEARCH.md`, `top100_players.json/csv`). Код игры при этом не менялся.

Допущения, которые пользователь пока не подтвердил:
- Тиры поняты как S/A/B/C/D/E (в сообщении было «С, А, Б, Д, Е»). S = Синнер, Зверев, Алькарас, Джокович; A = места 4–15; B = 16–35; C = 36–60; D = 61–80; E = 81–100.
- Имена «чуть изменены» черновым списком (колонка `game_name`), реальные имена только в ресерче.
- Игроки мужские (ATP); WTA не брали.

**Why:** пользователь хочет 100 персонажей с редактором внешности (кожа, причёски, одежда, левша/правша) и тирами; сначала просил только ресерч.

**How to apply:** следующий шаг по плану — вынести ростер в данные и переделать `Athlete._build` (`work/tennis/scripts/athlete.gd`) под словарь внешности. Помнить: сейчас внешность соперника в игре вообще не применяется (`cpu.setup` вызывается один раз, `shirt` из `opponents.gd` не читается), а левша в риге не поддержан (всё считано «вправо»). Источник данных о руке/бэкхенде проверен: Берреттини и Ханфман — двуручные (пользователь это подтвердил).
