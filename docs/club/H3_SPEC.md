# H3. Крытая арена — спецификация

Поток B, ветка `v02-club`. Основа: [CLUB_BRIEF.md](CLUB_BRIEF.md) (разделы 2, 3),
[CLUB_HUB_TZ.md](../CLUB_HUB_TZ.md) раздел 6, [H2_SPEC.md](H2_SPEC.md) (система построек).
Онлайна в v0.2 нет: хозяин комнаты на своей арене — только подготовленный контракт.

## 1. Цель

Слева от главного корта вырастает своя крытая арена, где проводишь свои матчи. Уровни
меняют её вид и открывают покрытия. Внутри — тренировка; позже — онлайн у себя.

**Готово, когда:** арена строится у прораба (3 уровня), тренировка на арене играется на
выбранном покрытии со своей физикой, вид арены соответствует уровню, FPS матча на арене
не хуже Нью-Йорка, подготовлено публичное состояние клуба для онлайна.

## 2. Уровни (через `ClubBuilds`, id `arena`)

| Ур. | Снаружи (в клубе) | Внутри (локация `arena`) | Польза | Цена |
|---|---|---|---|---|
| 0 | площадка с забором стройки, табличка «Арена» | — | — | — |
| 1 | ангар (полукруглая крыша, ворота) | один фонарь, корт хард, голые стены | своя тренировка в зале | 250 |
| 2 | зал (стены, окна, вывеска) | трибуна на одну сторону, табло-доска | + грунт | 700 |
| 3 | арена (купол, неон с именем клуба) | трибуны по кругу, болельщики, табло с именем и счётом, прожекторы | + трава, вечерний свет | 1300 |

Открывается: после 5 забегов или корта ур. 2 (что раньше). Фразы тренера — как в H2.

## 3. Локация `arena`

- `scripts/locations.gd`: **добавить** `{"id": "arena", "name": "Своя арена",
  "surface": <выбор>, "scenery": "res://scripts/club/scenery_arena.gd", "hidden": true}` —
  не показывается в выборе локации турнира.
- `scripts/club/scenery_arena.gd` (`extends Scenery` или общий базовый класс без неба):
  закрытая коробка ~44×30 м, нет неба и облаков, нет ветра (если ветер появится в физике —
  0 в зале), свет: на ур. 1 одна лампа над кортом + слабый рассеянный, на ур. 3
  прожекторы (эмиссия + 1 `DirectionalLight3D` сверху, тени только у игроков).
- Покрытие: `Court.set_surface(id)` и `BallPhysics` уже умеют хард/грунт/траву — арена
  берёт выбранное игроком (`club.arena_surface`, по умолчанию хард).
- Трибуны и болельщики — та же процедурная толпа MultiMesh, что в H2 (цвет клуба).
- Табло (ур. 2–3): `Label3D` или `SubViewport` 256×64 (на «Низкой» — без
  `SubViewport`, только `Label3D`): имя клуба, счёт матча из `GameEvents.point`.
- Звук: свой фон — гул зала и эхо (шина с `AudioEffectReverb`, room 0.6), аплодисменты
  на ур. 3 после хороших очков (`GameEvents.point`).

## 4. Вход и экран арены

- Круг у дверей арены (−22, 0): кнопка «Арена».
- Экран арены (новый `scripts/ui/screens/club_arena.gd` поверх рамки `TournamentUI`):
  карточки покрытий (`GameCard`: хард / грунт / трава; закрытые — силуэт и «уровень 2»),
  главное действие «Тренировка», позже «С другом» (серое, «онлайн скоро»).
- «Тренировка» = нынешняя `practice`, но `set_location("arena")` с покрытием арены.
  После тренировки «← Назад» возвращает героя к дверям арены.
- Крючок в `Main`: действие `"arena_practice"` (arg — покрытие) → `_start_practice` с
  локацией `arena`. Одна ветка в `_on_ui`.

## 5. Контракт для онлайна (подготовить, не подключать)

- `ClubState.to_public() -> Dictionary`: уровни мест, цвет, имя клуба, покрытие арены —
  только видимое, без золота и пользы. Размер ≤ 1 КБ.
- `scenery_arena.gd` строится из такого словаря (`build_from(state)`), а не из
  `SaveData` напрямую: гость увидит арену хозяина.
- В онлайн-матче `Club.utility_enabled = false` (уже из H2).
- Описать в `docs/ONLINE_PVP_TZ.md` одним абзацем (через сборщика): хозяин комнаты шлёт
  `club_public` в `join`/`lobby`.

## 6. Тесты

- арена каждого уровня строится headless без ошибок, для каждого покрытия;
- тренировка на арене: физика покрытия = `BallPhysics.SURFACES[surface]`;
- покрытие закрыто → карточка не выбирается;
- `to_public()` не содержит `gold`, `spent`, пользы; `build_from(to_public())` даёт тот же
  вид;
- автоигра `--autoplay --points=20 --location=arena` проходит без ошибок.

## 7. Снимки и производительность

Снаружи (клуб) на уровнях 0–3, внутри с кадра матча на уровнях 1–3 и трёх покрытиях,
экран арены — 720×1564 и 720×1480. FPS матча на арене ур. 3 на «Низкой» ≥ 50, draw calls
≤ 70.
