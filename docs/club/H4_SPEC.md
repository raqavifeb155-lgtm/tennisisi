# H4. Флекс и живость — спецификация

Поток B, ветка `v02-club`. Основа: [CLUB_BRIEF.md](CLUB_BRIEF.md) (разделы 3, 6, 8),
[H2_SPEC.md](H2_SPEC.md), [H3_SPEC.md](H3_SPEC.md). Без онлайн-матчей; «Позвать в клуб» —
просмотр чужого клуба, это не матч.

## 1. Цель

Клуб рассказывает о тебе и живёт сам: статуя после титула, болельщики, тренер с
маршрутом, вечер по часам телефона, оставшиеся места с уровнями (раздевалка, тренерская,
доска), и друга можно позвать посмотреть клуб по ссылке.

**Готово, когда:** все 9 мест брифа строятся до максимума; статуя растёт с титулами;
вечером в клубе горят фонари и неон; друг по ссылке гуляет по твоему клубу (только
смотреть); FPS по бюджету с полностью отстроенным клубом.

Польза — через `Skills.club` (источник модов, который сборщик добавляет в `Skills.mod()`

для выносливости (согласовать имя). Ячейки Шкафчика и переброс — API потока A

стене в цвете редкости; без Шкафчика — последнюю ракетку из сохранения.

## 3. Статуя

У входа (6, 34). Появляется сама после первого титула (не покупается): бронза → серебро
(5 титулов) → золото (15). Поза — замершая поза героя с поднятой ракеткой (поза из
`Athlete`, один кадр, запечённый в меш при постройке клуба), материал — металл
`ClubMaterial` с бликом. Табличка: имя клуба и «Титулов: N». Тренер при первом
появлении: «Тебе поставили памятник. Не зазнавайся».

## 4. Живость

- **Болельщики** на трибунах (уровни из H2): лёгкое покачивание в шейдере (без CPU),
  хлопки после постройки и когда герой выходит на корт (`applause.ogg`, тихо).
- **Тренер**: маршрут по клубу (корт → тренерская → лавка → бар, если есть), остановки
  5–15 с; облачка при подходе (не чаще 20 с), «почти готово» про ближайшую постройку.
- **Пушка для мячей** (тренерская ур. 2): на главном корте раз в 3–5 с вылетает мяч и
  скачет — та же точка `ball_machine`, что у обучения сборщика; не мешать обучению
  (во время обучения пушку клуба не запускать).
- **Время суток:** по часам телефона. 06:00–19:00 — утро/день (как сейчас), 19:00–06:00 —
  вечер: солнце низко и оранжевое, небо темнее, фонари корта (корт ур. 2), неон (вход ур.
  3, бар ур. 3) и окна города светятся (эмиссия), на «Высокой» — до 2 точечных ламп.
  Переход плавный за 2 с, если смена случилась при открытом клубе.

## 5. «Позвать в клуб»

- Кнопка у прораба (вход): «Позвать в клуб» → ссылка Telegram
  `t.me/<бот>?startapp=club_<id>` через `Telegram.WebApp.openTelegramLink` (окно
  «поделиться»).
- Чтобы друг увидел клуб, нужен публичный снимок: `ClubState.to_public()` (из H3)
  выкладывается на сервер `fi` при каждой постройке: `PUT /club/<telegram_user_id>`
  (≤ 1 КБ), `GET /club/<id>` — для гостя. **Изменение сервера — только с «ок»
  владельца**, выкладка — сборщиком.
- Гость открывает игру с `startapp=club_<id>` → клуб хозяина в режиме «только смотреть»:
  ходить можно, кнопок мест нет, чип золота скрыт, сверху плашка «Клуб Димы · в гостях»
  и «Вернуться в свой клуб». Кнопка «Сыграть с ним 1 на 1» — серая, «онлайн скоро».
- Нет сети или клуба нет — гость попадает в свой клуб с одной строкой «Клуб не
  открылся».

## 6. Тесты

- статуя: 0 титулов — нет, 1 — бронза, 5 — серебро, 15 — золото;
- вечер: часы 18:59 → день, 19:00 → вечер, 05:59 → вечер (подменяемый источник времени);
- `Skills.club` даёт восстановление 0.02…0.05 и пуст в онлайне;
- гостевой режим: из `to_public()` строится клуб, кнопки мест не появляются, золото не
  видно, покупка невозможна;
- оставшиеся места строятся на всех уровнях headless.

## 7. Снимки и производительность

Весь клуб на максимуме днём и вечером (общий план и каждое место), гостевой режим,
статуя трёх видов — 720×1564 и 720×1480. `--club-walk` на «Низкой» с полностью
отстроенным клубом и вечером: FPS ≥ 50, draw calls ≤ 70, треугольники ≤ 25k.
