# H2. Стройка — спецификация

Поток B, ветка `v02-club`. Основа: [CLUB_BRIEF.md](CLUB_BRIEF.md) (разделы 3, 5, 8, 9),
[H1_SPEC.md](H1_SPEC.md) (клуб уровня 0 уже есть). Слияние — после B-H1 и вместе с A-3
(Тотализатор в баре).

## 1. Цель

Золото впервые тратится: у прораба и у мест покупаются уровни пяти мест — **главный
корт, трибуны, вход, трофейная, бар**. Каждая покупка меняет 3D, сохраняется и (где
положено) даёт маленькую пользу с потолком.

**Готово, когда:** золото списывается и сохраняется (в том числе в облаке Telegram), клуб
меняется на каждом уровне, польза работает, с потолком и выключена в онлайне, момент
постройки пропускается тапом, бейджи считают постройки по карману, тесты и снимки
каждого уровня готовы.

## 2. Данные (`scripts/club/club_builds.gd`, `class_name ClubBuilds`)

Таблица — данные, не код сборки. Цена = `round(price × CLUB_PRICE_SCALE)`,
`CLUB_PRICE_SCALE := 1.0`.

Каждый уровень — запись: `{level, title, now_text, next_text, perk_text, price, build:
Callable или имя функции сборки в ClubWorld}`. Открытие: трофейная — после первого
забега, бар — после первого титула, остальные — сразу.

Публичное API: `level(id)`, `max_level(id)`, `next_price(id)`, `can_afford(id)`,
`affordable_count()`, `buy(id) -> bool` (списывает `SaveData.gold`, повышает уровень,
`SaveData.save()`), `gold_win_bonus() -> float`, `bet_limit() -> int`.

## 3. Сохранение (`SaveData`, новая секция `club`)

```
[club]
levels = {"court": 1, "stands": 2, ...}
color = 0            # цвет клуба 0..3 (синий, изумрудный, бордовый, графит)
name = "Клуб Димы"   # "" = по умолчанию из Telegram
spent = 340          # всего потрачено на стройку
last_location = "park"; last_format = 1   # из H1
```

**Облако:** `SaveData._score` сейчас учитывает золото (`gold × 0.1`) — после покупки
копия «до покупки» в облаке окажется «больше» и откатит её. Нужен крючок: в `_score`
прибавить `club.spent × 0.1` (вес как у золота). Это правка старой функции — согласовать
со сборщиком и написать в описании ветки. Тест: покупка не уменьшает `_score`.

## 4. Польза

- **Трибуны → золото за победы.** `ClubBuilds.gold_win_bonus()` = 0.02 × уровень. Крючок в
  `Tournament.gold_for_win` (файл потока A): одна строка
  `× (1.0 + Club.gold_bonus())`, где `Club.gold_bonus()` = 0 в онлайне. Согласовать с A
  через сборщика.
- **Бар → Тотализатор.** Экран и логика — поток A, действие `"bets"`. Бар даёт
  `ClubBuilds.bet_limit()` = 50 / 150 / 500 и открывает кнопку «Тотализатор» у бара (до
  слияния A-3 кнопка показывает «скоро»).
- **Трофейная:** Кодекс и счётчик удачи — «скоро», пока их нет. Видимая часть работает:
  кубки = `SaveData.titles`, лучшие вещи — из Шкафчика/сохранения потока A, если есть,
  иначе лучшая ракетка последнего забега (новое поле `club.best_item`).
- Всё через одну точку `Club.utility_enabled` (false в онлайн-матче; онлайна в v0.2 нет,
  но флаг и тест есть).

## 5. Прораб и карточки

- **Прораб** (вход, круг (0, 36)): кнопка «Прораб» открывает экран построек — сверху
  живой 3D (вуаль не темнит верх: `VEIL` только под карточками), внизу горизонтальная
  лента карточек `GameCard` всех открытых построек, свайп и стрелки ‹ ›. Карточка в
  центре = выбранная: камера (`club_camera.gd`) переезжает к постройке за 0,4 с.
- **«↑ 340» у места** (маленькая круглая кнопка справа от контекстной) открывает тот же
  экран сразу на карточке этого места. Показывается, только если хватает золота.
- **Карточка:** название, уровень точками ●●○○○, «Сейчас → Будет» одной строкой, польза
  «+4% → +6%», цена. На максимуме — золотая рамка и «Максимум». Не открыто — силуэт и
  условие («после первого титула»).
- **Призрак:** пока карточка в центре, в 3D стоит следующий уровень полупрозрачным
  (альфа 0.35, золотой контур через обводку `ClubMaterial` золотого цвета). Строится той
  же функцией уровня, что и настоящий.
- **Кнопка внизу:** «Построить · 340 ●» (Primary); не хватает — обычная тёмная, «Нужно ещё
  120», нажатие трясёт чип золота; максимум — кнопки нет.
- **Выбор при покупке:** корт ур. 3 — ряд из 4 кружков цвета клуба на карточке перед
  кнопкой; вход ур. 1 — поле имени (`LineEdit` в стиле UiTheme, до 16 знаков, по
  умолчанию из Telegram `initDataUnsafe.user.first_name` → «Клуб Димы», фильтр мата —
  короткий список в `club_builds.gd`, при совпадении — «Такое имя не подойдёт»).
- **Бейдж прораба:** `affordable_count()`, красная точка над доской прораба в 3D и в
  быстром переходе.

## 6. Момент постройки

~2 с, тап в любом месте → сразу итог (новый уровень на месте, золото списано).

1. монеты вылетают из чипа и летят к постройке (`TournamentUI._fly_coins` в обратную
   сторону: из чипа в точку проекции постройки), счётчик убывает — 0,5 с;
2. камера подлетает ближе — 0,4 с;
3. леса (рамка из брусков, растёт из земли), пыль (CPUParticles, на «Низкой» 12 частиц,
   иначе 40), золотая вспышка-кольцо у основания — 0,3 с;
4. старый уровень уходит в землю, новый вырастает с отскоком: масштаб по y 0 → 1.08 →
   1.0, 0,5 с;
5. звук «бум» (новый `build_thud` в `tools/gen_sfx.py`) и вибрация
   `TelegramApp.haptic("heavy")`; если трибуны ≥ 1 — `applause.ogg`;
6. тренер говорит фразу облачком (по фразе на постройку, раздел 7).

Двойное нажатие, выход посреди анимации, нехватка золота после анимации — невозможны:
золото списывается и сохраняется **до** анимации, анимация только показывает.

## 7. Фразы тренера (по одной на постройку и уровень, до 60 знаков)

Примеры: корт 1 — «Свежая краска! Мяч теперь отскакивает честно»; трибуны 1 — «Две
скамейки. Уже кто-то придёт посмотреть»; трибуны 3 — «Трибуны готовы. Теперь тебя слышно
с набережной»; вход 1 — «Клуб Димы. Звучит!»; бар 1 — «Газировка есть. Ставки — после
титула». Полный список — в `club_builds.gd` рядом с уровнем.

«Почти готово» при подходе к прорабу: «До трибун 12 золота — ещё один забег».

## 8. 3D по уровням

Всё, что меняется по уровням, — кодом в `ClubWorld` (функция на уровень или параметры):
корт (покрытие, линии, сетка, логотип — `Decal` или плоскость), трибуны (MultiMesh
сидений, болельщики — процедурная толпа по образцу `scenery_chatrier.gd`, в цвете клуба,
на «Низкой» половина), ворота и вывески (`Label3D`, неон — эмиссия), полка/витрина и
кубки (процедурные кубки: цилиндры и лейка, MultiMesh), бар (стойка кодом, мебель —
KayKit Restaurant Bits через `ClubMaterial`), машины (Kenney Car Kit).

Модели: скачать наборы из брифа (раздел 9), перекрасить атласы в палитру, уменьшить
до 128 px, `assets/club/*.glb`, записать лицензии в `CREDITS.md`. Пакет моделей
докачивается после старта; пока его нет — коробки кодом того же размера.

## 9. Тесты

- `buy`: списывает ровно цену, повышает уровень, не даёт купить без золота и выше
  максимума, сохраняет; сохранение → загрузка даёт те же уровни, цвет, имя;
- `_score` не уменьшается после покупки (облако не откатывает стройку);
- `gold_win_bonus` = 0 / 0.02 … 0.10, не больше 0.10; 0 при `utility_enabled = false`;
- `bet_limit` по уровням бара; бар закрыт до первого титула;
- `affordable_count` при разном золоте;
- каждая функция уровня строится без ошибок для всех уровней всех 5 мест (headless);
- фильтр имени: пустое → имя по умолчанию, длиннее 16 — обрезается, мат — отказ;
- момент постройки: тап посреди — итоговое состояние то же, что без тапа.

## 10. Снимки и производительность

`tools/club_shots.gd --builds`: каждое из 5 мест на каждом уровне (кадр места), экран
прораба (лента, призрак), момент постройки на середине, «Нужно ещё 120», «Максимум» — на
720×1564 и 720×1480. Замер `--club-walk` на «Низкой» при всех местах на максимуме:
бюджет H1 (раздел 7) не превышен.
