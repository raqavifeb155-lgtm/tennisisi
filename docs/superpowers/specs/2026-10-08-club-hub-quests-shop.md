# Хаб, поток B: задания тренера, постройки магазина и раздевалки, место блэкджека, замки локаций

Поток B, ветка `v02-club`, 2026-10-08. Основа — утверждённая спека
`2026-10-08-v02-hub-economy.md`, разделы 2, 4, 5, 6 (место) и 9.

## 1. Задания тренера (раздел 5) — `scripts/club/club_quests.gd`

**Данные.** `SaveData.club["quests"]`:
```
{run: "<seed забега>", list: [квест ×3 (+ выполненные прошлого забега, если не забраны)],
 issued: всего выдано, claimed: всего забрано}
квест: {tpl, text, event, kind: "count"|"max", scope: "match"|"run", need, have,
        done, claimed, gold, item (bool), tier}
```

**Пул — 15 шаблонов** (у каждого три порога: остров 0 / 1 / 2+ и базовое золото 20–60):
эйсы за матч · очко со стилем ×N · укороченные-виннеры · очки у сетки · розыгрыш ≥ N ударов ·
матч всухую (соперник без гейма) · загнать соперника (выносливость < 20%) · PERFECT за матч ·
виннеры форхендом · свеча-виннер · смэш-виннер · подача ≥ N км/ч · N очков подряд ·
матчей выиграно в забеге · достать мяч в прыжке.

**Выдача.** Забег узнаётся по сиду турнира (`Tournament.rng.seed`, переживает сохранение).
Новый забег (первый матч или клуб видит новый незаконченный турнир) → 3 разных шаблона, сид
выдачи = сид забега (одинаковый забег — одинаковые задания). Невыполненные прошлого забега
сгорают; выполненные, но не забранные — остаются до «Забрать». Сложность — по острову забега:
`Locations.tier()` (поток A); пока API нет — Нью-Йорк 0, Испания 1, Англия 2, Париж 3.

**Прогресс** — только по `GameEvents` и `RunHub.style_scored` (main.gd не трогаем), только в
матчах турнира. Счётчики с `scope: match` обнуляются в начале матча, если не выполнены.
Выполнено → `GameEvents.quest_done({index, text})` (новый сигнал, для будущего тоста C) и
сохранение.

**Награда.** Золото = база × множитель острова (1.0 / 1.3 / 1.6 / 2.0). Каждое третье
выданное задание несёт ещё вещь (редкая 80% / эпическая 20%). Вещь кладётся: в шкафчик, если
у потока A есть `Locker.put` (вызов через глобальный класс); иначе в сумку идущего забега;
иначе — в `SaveData.club["quest_items"]` (ждёт шкафчик A).

**В клубе.** Тренерская: доска мелом в 3D — три строки заданий с прогрессом; бейдж над
тренерской = очки навыков + задания к получению. Кнопка у тренерской: есть что забрать —
«ЗАБРАТЬ · +N ●» (забирает все, монеты летят в чип, тренер говорит фразу), тихая вторая —
«Навыки»; иначе главная «НАВЫКИ», тихая — «Задания» (экран-доска: карточки заданий с
прогрессом и наградой). Тренер на корте, если есть награда, зовёт: «Есть награда — заходи».

## 2. Постройки `shop` и `locker` (раздел 2, 1)

- `ClubBuilds`: `shop` — 0 «ларёк» (2 вещи до редкой), 1 «лавка» 150 (3 вещи до эпической,
  струны), 2 «бутик» 450 (4 до легендарной, витрина светится); `locker` — 0 (1 ячейка),
  1 ряд шкафчиков и зеркало 80 (2), 2 стена ракеток 250 (3), 3 гардероб с подсветкой 550 (4).
  Открываются после первого забега. `ClubBuilds.locker_slots()`, `shop_stock()`,
  `shop_max_rarity()` — для потока A.
- Место магазина и раздевалки двигается уровнем постройки (`build`), витрина — 2/3/4
  стойки с вещами, на уровне 2 подсвечена; раздевалка — шкафчики по ячейкам, стена ракеток,
  гардероб с подсветкой. Призрак следующего уровня у прораба — и для комнат.
- Экраны — поток A: `club_shop` и `club_locker` клуб отдаёт `RunShop.ui_action(main, a, arg)`
  / `RunLocker.ui_action(...)`, если такие классы есть (как `RunBets`, `RunBag`); иначе —
  нынешний экран магазина «скоро» и нынешняя Раздевалка.

## 3. Место `blackjack` (раздел 6)

Терраса бара, справа от рулетки: круг (25, −29.6), r 1.6, стол-полумесяц с зелёным сукном
(заглушка: поток E ставит свою сцену на маркер `blackjack_table`, `ClubWorld.blackjack()`
→ Transform3D), открывается после первого титула, кнопка «Блэкджек» → `club_blackjack`. Пока
у потока E нет `ClubBlackjack.open(club)` — карточка «Блэкджек · скоро».

## 4. Замки локаций (раздел 4)

«Другое место» у корта открывает экран клуба «Куда едем?»: локации с покрытием и
уровнем острова; закрытые — с замком и подсказкой `Locations.unlock_hint()` («за титул в
Испании»), нажать нельзя. API читается через скрипт (`Locations.unlocked/unlock_hint/tier`);
пока у A его нет — всё открыто, подсказок нет. Выбор → прежнее действие `location`.

## 5. Долгая стройка (раздел 13 хаб-спеки, утверждено сборщиком)

- **8 построек по 5 уровней:** корт, трибуны, вход, магазин, раздевалка, трофейная, бар и новая
  **тренерская** (`coach`).
- **Цены:** база `p` × 1 · 2.2 · 5 · 11.5 · 26 (округление до 5).
  - Базы: корт 40, трибуны 50, вход 45, магазин 60, раздевалка 40, трофейная 45, бар 50, тренерская 40.
  - Весь клуб ≈ 16 900 золота.
  - Множитель `CLUB_PRICE_SCALE` для перебаланса.
- **Ценность растёт с уровнем:**
  - трибуны: +2…+10% золота за победы;
  - бар: лимит ставки 25 / 50 / 100 / 150 / 300 / 500;
  - магазин: 2 / 3 / 4 / 4 / 5 / 5 вещей, редкость до редкой / эпической / легендарной;
    бесплатный переброс витрины с ур. 3; скидка 20% на струны на ур. 5;
  - раздевалка: ячейки 1 / 2 / 2 / 3 / 3 / 4, скидка на страховку 10% (ур. 2–3), 25% (ур. 4–5);
  - тренерская: +1…+5% восстановления, 1 переброс наград за забег на ур. 5.
  - Это отступает от раздела 2 хаб-спеки (магазин 150 / 450 и 3 уровня): раздел 13 новее.
- **Уровни 4 и 5 строятся за 2 и 3 забега.**
  - Золото списывается и сохраняется сразу, на месте стоят леса.
  - Уровень готов, когда `SaveData.played` дорастёт до записанного значения.
  - Момент постройки — при следующем входе в клуб.
  - Данные: `SaveData.club.building = {id: {level, until}}`.
  - `_score` учитывает `spent`, поэтому откат облака не отменяет оплаченные леса.
