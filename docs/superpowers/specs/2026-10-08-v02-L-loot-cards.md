# v0.2 L — карточки лута и наград (поток L)

Замечания владельца: переворот показывал уже видимый текст; вещи не имели «тела» и не было видно,
куда они попадают; выбор и лут должны давать ощущение выигрыша.

## L-1. Переворот со смыслом (решение по каждому экрану)
Причина бага: `card.face_down = true` ставился после `_ready()`, лицо не прятали, «переворот» менял лицо на то же лицо.
Теперь `face_down` задаётся до добавления в дерево (`_card({"face_down": true})`), текст под рубашкой прозрачен
(не `visible=false`: скрытая коробка не раскладывается, перенос слов считал бы по букве).

| Экран | Решение |
|---|---|
| Награда 1 из 3 | Рубашкой вверх (цвет редкости, узор, без текста), въезд снизу с отскоком, ожидание 0.8 с, затем по очереди через 0.15 с; тап по рубашке открывает весь ряд сразу (0.06+0.09 с на карту); взять можно только открытую |
| Лут (трофей) | Без переворота: вещь уже видна на корте и в итоге матча («Трофей: …»). Большая картинка вещи «выскакивает» над карточкой, вспышка/частицы на въезде |
| Перк навыка | Без переворота: всё известно заранее. Въезд снизу с отскоком + один блик |
| Магазин, сумка, шкафчик, итоги | Без изменений в поведении, только картинки вещей |

## L-2. Картинка вещи (`scripts/ui/item_thumb.gd`)
Меши из `AthleteGear` (ракетка; пара кроссовок; предплечье с напульсником), SubViewport 192 px, прозрачный фон, камера
три четверти, свет и тун-обводка тела. Кэш в памяти по облику: каталожная — `id`, сгенерированная — слот+редкость,
пустой слот — «стоковая». **Уровень в ключ не входит** (облик не меняется), «ур. N» рисуется плашкой поверх.
Бюджет: вещь берётся из очереди, ставится перед камерой, рисуется и читается в одном кадре; пул из 3 SubViewport →
не больше 3 за кадр; вьюпорты живут, пока есть очередь (+3 с). Свечение редкости — рисованный круг за картинкой
(у эпической и выше живой).

## L-3. Полёт (`scripts/ui/item_fx.gd`, `bag_chip.gd`)
Чип сумки (значок + число вещей: надето + в сумке; в магазине/шкафчике — шкафчик + едут в забег) в верхней панели,
только знак, не кнопка. Кнопка/карточка несёт «план» (`TournamentUI.carry`/`carry_coins`), `_press` выполняет его
после нажатия и до смены экрана: картинка вылетает с карточки по дуге (0.55 с), чип подпрыгивает, число растёт,
плашка «+1». Покупка: то же + золото в чипе уходит вниз. Продажа: монеты из карточки в чип золота (`_fly_coins(wait)`).
Где чипа нет: экран «Сумка» (с «Назад», золотом забега и банком чип не помещается в 720 px) — там без чипа.

## L-4. Эффект выигрыша (`scripts/ui/reveal_fx.gd`)
Обычная/редкая: только блик (раз). Эпическая+: вспышка цвета редкости, вибрация (`medium`/`heavy`/`perfect` через
`Tuning.vibration`), искры (14/26/40, один узел), звук `reward` (питч 1.0/1.12/0.8, громче с редкостью), у легендарной
и выше лучи за карточкой. Мифическая: экран темнеет на 1.3 с, остальные карточки тонут, карточка вспыхивает,
заголовок «МИФИЧЕСКАЯ».
