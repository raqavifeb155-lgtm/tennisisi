# B-3. H2 — стройка пяти мест: как сделано

Поток B, ветка `v02-club`, 2026-10-08. Полная постановка — `docs/club/H2_SPEC.md`. Здесь
только решения реализации и отступления.

## Данные и API (`scripts/club/club_builds.gd`, `ClubBuilds`)

- Таблица H2 (корт 4, трибуны 5, вход 4, трофейная 3, бар 3 уровня) — данные: `title`,
  `now`, `next`, `perk`, `price`, `line` (фраза тренера). Цена × `CLUB_PRICE_SCALE`.
- API как в H2 §2: `level`, `max_level`, `next_price`, `can_afford`, `affordable_count`,
  `buy(id)`, `gold_win_bonus`, `bet_limit`, `is_open(id)`, `utility_enabled`.
- `bet_limit()` берётся из данных места бара (`ClubPlaces` уровень бара) — одно место
  правды. Уровень 0 бара (стол с рулеткой после первого титула) принимает ставку до 25:
  Тотализатор открывается после первого титула (решение владельца), а не после постройки.
- Сохранение — `SaveData.club`: `levels`, `color`, `name`, `spent` (словарь секции
  `club` уже пишется целиком; новых полей в `SaveData` нет).

## Отступления и крючки (вынесены в отчёт)

- **Облако:** `SaveData._score` должен учитывать `club.spent × 0.1`, иначе облачная копия
  «до покупки» перебьёт покупку. Это правка старой функции (`save_data.gd`), сделана
  **отдельным коммитом-крючком** в одну строку — подтвердить сборщику.
- **Польза трибун:** `ClubBuilds.gold_win_bonus()` готова (0,02 × уровень, ≤ 0,10, 0 при
  `utility_enabled = false`), но строку в `Tournament.gold_for_win` (файл потока A) я не
  добавляю: крючок за сборщиком/потоком A. Карточка трибун пишет пользу честно.
- **Имя клуба:** поле ввода при постройке вывески — в H2 упрощено: имя берётся из
  Telegram (`TelegramApp` → «Клуб <имя>»), без клавиатуры в Telegram-окне; смена имени —
  позже (экран настроек клуба). Фильтр имени (`ClubBuilds.clean_name`) уже есть и в
  тестах.
- **Цвет клуба:** при постройке корта ур. 3 — ряд из 4 кружков на карточке прораба;
  выбранный цвет красит покрытие корта клуба (слой поверх `Court`, только в клубе).
- **Модели наборов (KayKit, Kenney)** не качались: всё кодом коробками под `ClubMaterial`
  (H2 §8 разрешает «пока пакета нет — коробки кодом»).

## Экран прораба (в `ClubHud`, не `TournamentUI`)

Сверху живой 3D без вуали, камера над постройкой карточки; снизу одна карточка
`GameCard` с «‹ ›» и кнопка «Построить · 340 ●» / «Нужно ещё 120» / «Максимум»; «← Назад»
слева сверху. В 3D — призрак следующего уровня (та же функция уровня, материал
`ClubMaterial.ghost()`). «↑ 340» у места — маленькая круглая кнопка справа от
контекстной, открывает прораба сразу на этой постройке.

## Момент постройки

Золото списывается и сохраняется **до** анимации. Анимация ~2 с: камера ближе, золотое
кольцо-вспышка и пыль (`CPUParticles3D`, 12 на «Низкой», иначе 40), новый уровень
вырастает по y 0 → 1,08 → 1, звук и вибрация `heavy`, фраза тренера. Тап — сразу итог.
