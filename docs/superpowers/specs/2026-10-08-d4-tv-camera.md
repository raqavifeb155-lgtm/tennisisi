# D-4. Камера «как в ТВ» (HANDOFF 7.5) — спецификация

Поток D, ветка `v02-gameplay`. Дата 08.10.2026.

## Решение
- `GameCamera` — два ракурса: **Обычная** (как была) и **ТВ** (`Tuning.tv_camera`):
  камера высоко (17 м) за задней линией (z = 23 м), смотрит чуть за сетку, FOV 50° по
  ширине в портрете; корт целиком, игроки небольшие, камера лишь слегка (×0.12) ведёт
  игрока по ширине. Для альбомного экрана — свои числа (13 м, z 23, FOV 44°).
- Хранение: `SaveData.camera` = `"normal" | "tv"`, **новая секция** `[view]`, ключ `camera`;
  старые ключи не тронуты. Камера сама пишет выбор в сохранение по `Tuning.changed`.
- Флаг `--camera=tv` (бот, `input_test`, снимки).
- Крючки: `main.gd` — одна строка после загрузки сохранения
  (`Tuning.tv_camera = … SaveData.camera == "tv"`); `hud.gd` — одна строка в листе
  настроек, раздел «Игра»: переключатель «ТВ-камера». Если поток C переносит лист
  настроек (C-2), пункт переносится одной строкой `_switch(…, "tv_camera")`.
- Управление: тапы и свайпы переводятся в точки корта лучом из камеры
  (`Main._screen_to_ground`), поэтому работают в любом ракурсе. Проверено: `input_test`
  с `--camera=tv` зелёный; в `ai_test` — точка экрана возвращается в ту же точку корта
  (ошибка 0.000 м), весь корт в кадре, ноги игрока выше зоны джойстика (y 1104 из 1564).
- Снимки: `tools/camera_shots.gd` (обычная и ТВ, 720×1564 и `--size=1480`).
