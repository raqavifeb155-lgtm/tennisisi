# B-2. Места клуба — каркас (Магазин, Бар-Тотализатор с 3D-рулеткой, Раздевалка, Тренерская, корт с пушкой, площадка арены)

Поток B, ветка `v02-club`, 2026-10-08. Основа: HANDOFF 9.1 и 10, бриф потока B,
`docs/club/CLUB_BRIEF.md` (план клуба), B-1 (`2026-10-08-club-b1-h1-finish.md`).
Детальная логика мест и прокачки обсуждается с владельцем — поэтому всё, что место
показывает и делает, лежит **данными** в `scripts/club/club_places.gd` и меняется без
переписывания кода.

## 1. Данные места (`ClubPlaces.LIST`)

```
{ id, name, pos, r, unlock, sign, cam?, travel?, build?,
  levels: [ {label, action, note, ...своё}, ... ] }
```
- `levels[i]` — что место предлагает на уровне `i` (кнопка, действие, текст «что здесь»,
  свои параметры: `bet_limit` у бара, `offers` у магазина). Уровня нет в списке — берётся
  последний описанный. `ClubPlaces.state(id, level)` склеивает базу и уровень.
- Уровень места — `ClubPlaces.level(id)`: `SaveData.club.levels[build]` (стройка H2), без
  стройки — 0. `build` — id постройки, чей уровень двигает место (у бара `bar`).
- `travel: false` — места нет в быстром переходе (пушка рядом с кортом).
- `unlock`: `""`, `"played"`, `"title"`, `"never"` (как в H1).

## 3. Бар-Тотализатор: 3D-рулетка

Экран `run_bets.gd` (поток A) в клубе больше не открывается: «Тотализатор» у бара ставит
камеру над столом с колесом, внизу — фишки (10/25/50/100), три ставки «Синее ×2 /
Красное ×2 / Сетка ×35», строка результата, «← Назад». Логика — `Bets` (поток A) без
изменений: поле выпадает **до** анимации (`Bets.spin`), выплата `Bets.payout`, запись
`Bets.note`, ставка ≤ четверти золота (`Bets.max_stake`) и ≤ `bet_limit` уровня бара.

Колесо (`scripts/club/club_roulette.gd`, `ClubRoulette`): 37 лунок (0 — «сетка», нечётные
синие, чётные красные — `Bets.color_of`), радиус 0,95 м, конус 14°, кольцо лунок, купол
в центре. Мяч — настоящий теннисный (`BallPhysics.RADIUS`):
1. бежит по бортику навстречу колесу, теряет скорость;
2. сходит с бортика и катится/прыгает по конусу: полёт — `BallPhysics.integrate_free`
   (гравитация, сопротивление, Магнус), удар о поверхность — `BallPhysics.bounce` в
   системе нормали поверхности;
3. падает в кольцо лунок: отскоки о вращающееся дно — `BallPhysics.bounce` в системе
   дна (скорость относительно колеса), об ладки (перегородки) — подскок;
4. успокаивается в лунке и едет с колесом.

**Честность и заданное поле.** Траектория мяча считается заранее целиком (до анимации),
в системе отсчёта колеса без поворота. Колесо — сетка из 37 одинаковых лунок, поэтому
траектория не зависит от поворота колеса на целое число лунок: колесо ставится с таким
сдвигом, чтобы лунка, где мяч остановился, была выпавшим полем. Анимация только
показывает. Тап — досмотреть сразу (итог тот же).

## 4. 3D мест

- Магазин — открытый павильон, как раздевалка (стойка, стойка с ракетками, витрина).
  Содержимое зависит от уровня (`_room_shop(level)`).
- Бар — стол с колесом рулетки под зонтиком, стойка; дальше растёт по H2.
- Пушка — модель на маркере `ball_machine` (B-1).
- Площадка арены — забор стройки (H1).

## 5. Тесты

- у каждого места круг, `levels`, `state()` даёт кнопку на уровнях 0…5 (последний
  описанный повторяется); магазин после забега, бар после титула;
- маршрут от корта до магазина и до бара существует, круги проходимы;
- уровень места перестраивает его 3D без ошибок;
- рулетка: 40 случайных запусков × заданное поле → мяч всегда в этом поле, не выходит
  за чашу, есть отскоки, ≤ 8 с; ставка списывает и платит по `Bets`, сверх лимита —
  нельзя;
- магазин и место-описание открываются, «← Назад» — герой там же.
