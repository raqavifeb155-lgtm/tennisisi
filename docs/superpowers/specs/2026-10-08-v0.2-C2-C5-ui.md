# Поток C, v0.2: пауза, настройки, слои, графика, золото, статистика (C-2…C-5)

Дата: 2026-10-08. Ветка `v02-ui`. Основа — `docs/UI_FLOW_TZ.md` (утверждено), HANDOFF 7.2–7.4,
9.6, 10. Логику меню не пересобираем (HANDOFF 10): только пауза, настройки, слои, тексты.

## C-2. Пауза, настройки, слои

**Слои** — константы `UiTheme.LAYER_*` (UI_FLOW_TZ 5.5):
HUD 1 · плашка стиля 5 · HUD клуба 9 · экраны 10 · шторки 15 · пауза/настройки 20 ·
подтверждения паузы 25 · справочник 30 · загрузка 100. Числа пишутся только там
(файлы потоков A/B — `run_hub.gd` 5, `club_hud.gd` 9 — пусть перейдут на константы сами).

**Хозяин паузы** — `scripts/ui/modal_stack.gd` (`ModalStack`, узел внутри `Hud`):
- `push(id, node, pauses)` / `pop(id)` (снимает окно и всё над ним) / `top()` / `has()`;
- `get_tree().paused` = есть ли в стеке окно с `pauses`; `pauses` = окно открыто из матча;
- пишет `paused`, только когда его решение меняется (не мешает тестам и инструментам);
- если верхнее окно спрятали снаружи (`tools/run_shots.gd` прячет обучение) — оно снимается.
Больше никто `get_tree().paused` не трогает: `Tutorial.open/_finish` и `Hud._set_paused`
больше не ставят паузу сами.

**Окна** (все — полноэкранное затемнение `STOP`, добавлены в `touch.blocked_controls`,
чтобы касания не уходили в корт и в клуб под окном):
- `pause_sheet.gd` — нижняя шторка: «Пауза» и счёт; «Как играть» · «Настройки»;
  тихая «Выйти в клуб»; внизу золотая «ПРОДОЛЖИТЬ». Тап по затемнению = «Продолжить».
- `settings_sheet.gd` — лист настроек (перенос из `hud.gd`), во всю высоту (закрывает
  кнопку ⚙/❚❚), «ГОТОВО» закреплена внизу. Порядок по 6.2: Управление → Подсказки на
  корте → Звук → Графика → «Для разработчика ▸». Убрано: «Выйти в меню», «Как играть»,
  «Одноручный бэкхенд» (только Раздевалка, P1-5), FPS в заголовке «Графика».
- `confirm_sheet.gd` — нижняя шторка подтверждения: заголовок, что пропадёт, «Остаться»
  (золотая, безопасная) и «Выйти» (вторичная). Тап по затемнению = «Остаться».
- `icon_button.gd` — круглая кнопка 84×84 в стиле UiTheme: ⚙ вне матча, ❚❚ в матче
  (вместо стандартной «НАСТР»/«ПАУЗА»).

**Поведение:**
- ❚❚ в матче → пауза (игра стоит). ⚙ вне матча (клуб, его экраны, сетка, итог) → настройки,
  мир клуба живёт дальше (UI_FLOW_TZ 7.5).
- Пауза → «Настройки» → «ГОТОВО» → снова пауза. Пауза → «Как играть» → «Закрыть» → снова
  пауза (игра стоит всё это время).
- «Выйти в клуб»: турнирный матч → подтверждение «Выйти из матча? Матч начнётся заново,
  турнир сохранится»; тренировка → сразу, без подтверждения (6.1). В мини-игре «Трофей»
  кнопки выхода нет (иначе трофей достаётся без подач при «Продолжить» турнира) —
  только «Продолжить», «Как играть», «Настройки».
- Турнир или тренировка — `Hud` узнаёт из `GameEvents.match_started` (без крючка в `main`).
- Совместимость: `Hud._toggle_debug()` (шестерёнка клуба, потока B) и `Hud._debug_btn`
  (клуб прячет её на своём экране) остаются с тем же смыслом.

**Проба** `tools/overlay_probe.gd`: старые проверки + 3D-клуб (⚙ клуба, экран места
«Раздевалка», «?» из быстрого перехода), пауза → настройки → пауза, тап по затемнению,
подтверждение выхода из турнирного матча («Остаться» / «Выйти», турнир сохранён), выход из
тренировки без подтверждения, кнопки пауза ≥ 84 px и «ПРОДОЛЖИТЬ» в нижней трети.

## C-3. Графика

- `GraphicsQuality.is_phone()`: Android/iOS (родные и веб, в т.ч. iPadOS по касаниям,
  Telegram `tgWebAppPlatform=ios|android`).
- «Авто» на телефоне: ступени `[Средняя, Низкая]` (без «Высокой»); на компьютере как было.
- Пометка у «Высокой» и «Максимум»: в строке-описании «Может тормозить в Telegram» и
  значок «!» на кнопке пресета (`Выс !`, `Макс !`). У «Авто» на телефоне — «на телефоне не
  выше «Средней»».

## C-4. Золото: забег и банк

- Чип справа сверху = **банк** (`SaveData.gold`), всегда, как в клубе.
- Во время забега рядом — второй, тихий чип **«+75 · забег»** (золото забега, ещё не в банке).
- На итоге матча монеты летят в чип забега, а не в банк.
- На сетке — одна строка: «Золото забега +75 перейдёт в банк в конце турнира».
- Итоги турнира: строка «В банк: +75», монеты летят из чипа забега в банк, чип забега гаснет.

## C-5. Статистика матча

- `scripts/ui/match_tally.gd` (`MatchTally`): слушает `GameEvents` (`match_started` —
  обнуление, `shot`, `fault`, `point`, `match_finished` — фиксирует `last`).
- Строки (ты слева, соперник справа): Эйсы, Двойные, Виннеры, Невынужденные,
  Первая подача %, Форхенды, Бэкхенды; под таблицей «Лучший розыгрыш: N».
- **Невынужденная** = очко проиграно аутом/сеткой (не подача) ударом по мячу, пришедшему
  медленнее 24 м/с (~86 км/ч: давления нет, см. `Main.error_chance`); быстрее — вынужденная.
- Первая подача % = подачи, где первый мяч в корте / все очки на своей подаче.
- Форхенд/бэкхенд — по `side` удара (подачи не считаются).
- Крючки (`main.gd`, отдельными коммитами): в `GameEvents.shot` поля `side`, `incoming`,
  `serve`; новое событие `GameEvents.fault` (одна строка `emit` в `Main._fault`).
- Экран: `scripts/ui/screens/match_stats.gd` — блок на итоге матча поверх рамки
  `TournamentUI` (тонкий вызов из `show_result` вместо строки PERFECT/эйсы/розыгрыш).
  Нет данных (продолжение после перезагрузки) — старая строка.
