## 0. Решения владельца (2026-10-07)

| Вопрос | Решение |
|---|---|
| «Поделиться» | картинка лучшего очка + подпись + ссылка `t.me/TennisisiBot?startapp=…`, без сервера; видео — следующим патчем |
| Метки мяча (Огонь, Лёд, Тяжесть) | не в v0.2. Вещи работают через статы и триггеры без физики мяча; метки — в 2a вместе с зонами |
| Золото за стиль | ≈ +50% к призовым за матч: очко с трюком даёт очки стиля, за матч они превращаются в золото забега |
| Тотализатор | открывается после первого титула; ставка — фишки 10/25/50/100, но не больше 25% золота; после 3 проигрышей подряд — «перерыв?» |

Общие правила: ставки только на игровое золото, никогда на Stars; логика подписывается на
`GameEvents`, в `main.gd` — только маленькие крючки; экраны на `UiTheme` и `GameCard`.

## 1. Архитектура

```
GameEvents (autoload, main emits) ──► RunHub (Node, создаёт Main одной строкой)
                                         ├─ StyleMeter   ← StyleRules (чистые данные + evaluate)
                                         ├─ PointRecorder (кадры очка → повтор)
                                         ├─ RunEffects   ← Items (каталог вещей), Tournament.equip
                                         ├─ OppStamina   (модель «здоровья» соперника)
                                         └─ RunOverlay (CanvasLayer: плашка стиля, полоска STA,
                                                         цифры урона)
Tournament (чистое состояние забега): equip, bag, lineup[i].gear, golden, style_gold
Bets (чистая логика ставок) + SaveData-секции style, bets, golden
Экраны: scripts/ui/screens/run_*.gd поверх рамки TournamentUI
```

- **Чистая логика отдельно от узлов.** `StyleRules`, `Items`, `RunEffects`, `OppStamina`,
  `Bets`, `Tournament` — `RefCounted`/статические классы без сцены: тестируются headless в
  `tests/roguelike_test.gd`.
- **`RunHub`** живёт в дереве Main, держит ссылку на Main только для чтения состояния
  (`cpu.position`, `scoreboard`, `stamina`, `ai`, `tournament`) и для трёх действий:
  своя выносливость игрока (`main.stamina`), опыт за стиль (`main._gain_xp`), скорость/
  точность соперника (`main.ai.speed_mult`, `Tuning.ai_skill`, на время матча, с возвратом).
- Всё рогаликовое работает **только в турнире**. В тренировке нет ни стиля-золота, ни
  полоски соперника (плашка стиля показывается — это обучение языку трюков).

### Крючки в чужих файлах (весь список)

| Файл | Крючок |
|---|---|
| `main.gd` | `run_hub = RunHub.new(); add_child(run_hub); run_hub.setup(self)` в `_ready` |
| `main.gd` | `_set_opponent_mods`: снаряжение игрока = `RunEffects.equip_mods(t)` вместо `t.racket["mods"]` |
| `main.gd` | `GameEvents.knocked.emit(Who.CPU)` там, где соперник падает/теряет ракетку (если такое место есть) |
| `main.gd` `_on_ui` | ветки `bag`, `bag_pick`, `equip`, `sell`, `bets`, `bet_*`, `spin`, `replay`, `share` → `RunScreens`/`RunHub` |
| `tournament_ui.gd` | в `show_result`, `show_bracket`, `show_menu` — по одной строке `RunScreens.xxx(self, t)`, которая добавляет свои блоки |
| `game_events.gd` | при нехватке полей — новые поля в словарях (обратно совместимо) |
| `save_data.gd` | новые секции `style`, `bets`, `golden`; старые не трогаем |

## 2. A-1. «Очки стиля» и повтор лучшего очка

### 2.1. Трюки

Очко, выигранное игроком, оценивается: `очки = 10 × множитель`, множитель — произведение
множителей сработавших трюков (как killscore в How to Fish).

| id | Трюк | Условие (по событиям) | × | Скрыт |
|---|---|---|---|---|
| ace | Эйс | `point.reason == "ACE"`, победил игрок | 1.3 | |
| cannon | Пушка | эйс и подача ≥ 200 км/ч | 1.5 | |
| dead_ball | Мёртвый мяч | последний удар игрока DROP SHOT, второй отскок на половине соперника ближе линии подачи (|z| < 6.4 м) | 1.3 | |
| lob_over | Через голову | последний удар LOB, соперник в момент удара ближе 5 м к сетке, очко выиграно | 1.5 | |
| on_line | По линии | победный, VAR-отметка 0…10 см внутри | 1.3 | |
| marathon | Марафон | розыгрыш ≥ 20 ударов | 1.5 | |
| curl | Выкрут | последний удар TOPSPIN с `curl_k ≥ 1.3`, WINNER | 1.2 | |
| knife | Слайс-нож | последний удар SLICE, WINNER | 1.2 | |
| knockout | Нокаут | `knocked(CPU)` в этом розыгрыше | 2.0 | да |
| dive | В прыжке | последний удар игрока `diving` | 1.5 | да |
| comeback | Камбэк | игрок выиграл очко при 0:40 на своём счёте | 1.3 | да |
| perfect | Идеально | ≥ 3 удара игрока в розыгрыше, все PERFECT | 1.5 | |
| smash | Молот | последний удар SMASH, WINNER | 1.2 | да |
| masterpiece | Шедевр | итоговый множитель ≥ 5× (умножается ещё ×2) | 2.0 | да |

«В тело» и «Сквозь ноги» — когда появятся события (нет попадания в тело и удара между ног).
Скрытые трюки не показываются заранее (в будущем Кодексе — «???»), в плашке — с названием.
Очко без трюков даёт 0 очков стиля (плашки нет).

### 2.2. Золото и опыт

- За матч очки стиля копятся: `S`. Золото забега за стиль: `round(S × STYLE_GOLD × reward
  формата)`, `STYLE_GOLD` подбирается ботом так, чтобы стильный матч давал ≈ +50% к
  призовым круга (стартовое значение 0.05: 10 очков с ×2 = 20 → 1 золото).
- Начисляется в `Tournament.gold` на `match_finished` (до `record_match`), сохраняется в
  `t.results.back()["style"]`. На экране итога — строка «Стиль: +N золота · лучший ×4.2».
- Опыт: навык победного удара получает `BASE_XP × (множитель − 1) × 2` сверху (через
  `main._gain_xp`).
- `SaveData`, секция `style`: `best_mult`, `best_points`, `total` — рекорды на всю игру.

### 2.3. Плашка на экране

После выигранного очка над счётом появляется плашка: трюки выскакивают по одному
(0.18 с), множитель «СТИЛЬ ×2.4» тикает вверх, на последнем — вспышка и плашка улетает к
счёту золота. Пропускается сама за ~1.6 с, не перекрывает мяч (верхняя треть). Цвет —
золото бренда; «Шедевр» — красный ободок. На «Низкой» графике — без частиц.

### 2.4. Повтор лучшего очка

- `PointRecorder` пишет каждый физический кадр розыгрыша (30 Гц достаточно): позицию мяча,
  `global_transform` всех `Node3D` в моделях двух игроков, позицию камеры. Память: один
  розыгрыш ≈ 600 кадров × ~60 трансформов — держим текущий и лучший за матч.
- Лучшее очко матча — с наибольшими очками стиля (при равенстве — длиннее розыгрыш). Если
  стильных очков не было — повтора нет.
- На экране итога матча — карточка «ЛУЧШЕЕ ОЧКО · СТИЛЬ ×3.1 ▶». Тап: экраны прячутся,
  розыгрыш проигрывается на корте (обработка игроков на паузе), сверху плашка стиля, тап —
  пропустить. После повтора — снова итог, на карточке кнопка «Поделиться».
- **Поделиться:** снимок кадра победного удара (из повтора) + плашка → PNG. Порядок:
  `navigator.share({files:[png], text, url})`, если браузер умеет файлы; иначе
  `web_app_open_tg_link` на `t.me/share/url?url=<ссылка>&text=<подпись>` (подпись и
  ссылка, превью бота); вне веба — PNG в `user://`. Подпись: «СТИЛЬ ×5.2 · Эйс · Пушка
  214 км/ч — TENNISISI», ссылка `https://t.me/TennisisiBot?startapp=style`.

## 3. A-2. Вещи и выносливость соперника

### 3.1. Слоты и сумка

- `Tournament.equip := {racket, shoes, band}` (пустой словарь = стандартная вещь),
  `bag: Array` до 6 вещей. Миграция: старое поле `racket` → `equip.racket`.
- Сумка открывается из сетки турнира (кнопка «Сумка · 2») и после лута. Экран
  `run_bag.gd`: три карточки надетого сверху, ниже сумка; тап по вещи — сравнение с
  надетой в том же слоте (строки статов, стрелки ↑↓) и действия «Надеть» / «Продать +N».
- Продажа — в золото забега: 3 / 6 / 12 / 25 / 50 по редкости.

### 3.2. Редкости

`Gear.RARITIES` — пять, цвета из `UiTheme.RARITY` (легендарная оранжевая, мифическая
красная). Обычные и редкие — генератор аффиксов (как сейчас), для всех трёх слотов
(у кроссовок — бег и выносливость, у напульсника — окна и подача). Эпические и выше —
уникальные вещи из каталога `scripts/run/items.gd` с триггером. Мифическая — не больше
одной за забег.

### 3.4. Шина эффектов `RunEffects`

- Триггеры: `on_match_start`, `on_hit(type, label, rally_n)`, `on_perfect`, `on_serve(kmh)`,
  `on_ace`, `on_point_won(tricks)`, `on_point_lost`, `on_game_won`, `on_break`,
  `on_tiebreak`, `on_change_ends`, `on_dive`.
- Условия `if`: `type`, `label`, `every_n` (каждый N-й удар), `streak` (PERFECT подряд),
  `reason`.
- Примитивы v0.2: `mod` (постоянный), `temp_mod(key, value, until)` (`point`/`game`/
  `tiebreak`/`run`), `opp_stamina(delta)`, `self_stamina(delta)`, `money(delta)`,
  `style_mult(trick, x)`, `style_all(x)`, `dmg_mult(source, x)`, `rule(name)`
  (`second_wind`, `dive_free`, `cannon_190`).
- `Skills.gear` = сумма модов надетого + активные временные моды; пересчёт на событиях.

### 3.5. Вещи соперника и лут

- `lineup[i].gear := {racket, shoes, band}` — у каждой вещи своя редкость: шансы
  62/27/8/2.5/0.5% на первом круге, со сдвигом вверх по кругам, модификаторам и боссу
  (сохраняем нынешние бонусы `loot`).
- Сила соперника от вещей: `Tuning.ai_skill += 0.01 × редкость` каждой вещи (их триггеры —
  в 2a, симметрично игроку).
- В сетке вещи не названы: видно «что-то светится фиолетовым» у самой редкой (эпик+),
  мифическая выглядит как обычная. На корте — свечение ракетки, как сейчас.
- Выпадение после победы: каждая вещь бросается отдельно 30/20/12/6/3% по редкости.
  Обычные и редкие — сразу в сумку (с плашкой на итоге), лучшая эпик+ — через «Трофей»
  (`pending_loot`, как сейчас).
- Награда 1 из 3: карточка вещи остаётся (обычная/редкая случайного слота) и кладёт её в
  сумку или надевает в пустой слот.

### 3.6. Выносливость соперника = «здоровье»

- `OppStamina` (0…100): урон по формуле дизайна 5.1:
  `урон = метры, пробежанные им за мяч × 0.6 + max(0, км/ч − 90) × 0.05 (если он отбил)`,
  `× 1.5 при PERFECT игрока`, плюс примитивы вещей. Отдых: между очками +6, смена сторон
  +20, между сетами +40 (коэффициенты подбирает бот).
- Ниже 40%: `speed_mult × (1 − 0.3 × усталость)`, `ai_skill − 0.12 × усталость`; на нуле —
  трусца. Значения выставляются на время матча и возвращаются на `match_finished`.
- Показ (`RunOverlay`): полоска над соперником (проекция из 3D), при уроне откалывается
  кусок и падает, белый «след урона» 0.4 с; цифры «−12» вылетают из груди по дуге: белые —
  бег, жёлтые — тяжёлый мяч, оранжевые — вещи; ≥ 25 — крупнее с обводкой. Ниже 40% —
  полоска пульсирует, соперник между очками в позе «руки на коленях» (`cpu.tired`).
  Пул из 8 цифр.

## 4. A-3. Тотализатор

- Открывается после первого титула (`SaveData.titles ≥ 1`). Вход: действие `"bets"` — из
  бара клуба (поток B), до слияния B — плитка в Клубе (одна строка в `show_menu`).
- **Рулетка «Мяч в поле»**: колесо из 37 полей — 18 синих, 18 красных, 1 «Сетка».
  Синяя/красная ×2 (шанс 18/37), «Сетка» ×35 (шанс 1/37). Шансы написаны на столе.
  Мяч скачет по колесу и останавливается в поле, выбранном честным броском заранее
  (`Bets.spin(rng)`); анимация только показывает результат.
- **Ставка на свой матч**: на экране сетки перед матчем — «Поставить на себя»:
  на победу ×1.3 / ×1.8 / ×2.5 / ×3.5 / ×6 по кругу (Джумхур … Джокович), «всухую»
  (соперник взял не больше 1 гейма, в формате тай-брейка — не больше 2 очков) — ×2.5 от
  коэффициента победы. Одна ставка на матч, платится на `match_finished`. Вайлд-кард
  переигрывает матч — ставка сгорает с проигрышем.
- Ставка: фишки 10 / 25 / 50 / 100, не больше 25% текущего золота (`SaveData.gold`).
  Только игровое золото. Выигрыш — в золото сразу.
- После 3 проигранных ставок подряд — мягкая подсказка «Перерыв? Корт ждёт» с кнопкой в
  Клуб (ставить можно дальше). Никаких «почти выиграл».
- `SaveData`, секция `bets`: `loss_streak`, `placed`, `won`, `net_hits`.
- Экран `run_bets.gd`: стол с колесом (рисуется кодом), фишки, две ставки, «Крутить».

## 5. A-4. Золотые соперники

- В `roll_lineup` каждый соперник, кроме первого, с шансом 1/50 — **золотой**: форма в
  золоте (look с золотыми цветами), одна его вещь гарантированно легендарная (или
  мифическая с прежним шансом), ×2 золота за победу.
- В сетке строка соперника в золотой рамке «ЗОЛОТОЙ», на корте — сообщение «ЗОЛОТОЙ
  ЗВЕРЕВ» и золотое свечение ракетки.
- `SaveData`, секция `golden`: id побеждённых золотых; в Тренерской/Трофейной (что есть) —
  «Золотые: 1 / 5».
- «Теневые» — после разблокировки, не в v0.2.

## 7. Порядок и готовность

A-1 → A-2 → A-3 → A-4, каждый этап — коммит(ы) в `v02-roguelike`, сообщение сборщику
«A-N готов к слиянию» со списком крючков и снимками. Вне объёма: метки мяча и зоны,
раскрытие редкости на корте с анимацией выхода, Шкафчик, карта, магазин, Кодекс, теневые
соперники, видео-клипы.
