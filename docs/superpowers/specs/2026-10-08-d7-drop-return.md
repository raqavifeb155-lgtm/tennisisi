# D-7. ИИ подбегает к укороченному и не бьёт — спецификация

Поток D, ветка `v02-gameplay`. Дата 08.10.2026. Жалоба владельца: «Когда даёшь укороченный, ИИ
подбегает к сетке и не бьёт — проигрывает очко».

## Воспроизведение
- `--bot-drop=0.4` (флаг `main.gd`, крючок): 40 % ударов бота игрока — укороченные (`ShotType.DROP`).
- `AiMetrics` печатает строку `player drops N: CPU hit … not hit: ran up … too far … own error … |
  drop won outright … points with a drop won by YOU a of b`.
  «ran up» — ИИ был в 1.3 м от мяча и не ударил (это и есть жалоба), «too far» — не добежал,
  «own error» — укороченный ушёл в аут/сетку, «won outright» — очко закончилось на нём в пользу игрока.
- Запуск: `godot --headless --path . --fixed-fps 60 -s tools/ai_bench.gd -- --points=300 --bot-sd=0.035 --level=8 --opp=rublev --seed=7 --bot-drop=0.4`
  (для слабого ИИ `--skill=0.0`).

## Причина
Укороченный (топ-спин −260…−320, темп 9 м/с) отскакивает в 1.5–2.5 м от сетки и *висит*: обратное
вращение держит продольную скорость на ~0.4 м/с при высоте до 1.1 м. `OpponentAI._check_hit` бил мяч
только в тот кадр, когда мяч пересекает плоскость удара (`me.z + CONTACT_FORWARD`) сверху вниз
(`_prev_rel > 0` и `rel <= 0`). Бегущий ИИ тормозит у цели (`_move_to` гасит скорость у точки), его
плоскость подползает к мячу медленнее, чем мяч опускается, `rel` остаётся +0.05 м, и второй отскок
отдаёт очко. `_anticipate_swing` тоже молчит (нужна скорость к ИИ ≥ 0.5 м/с). Предсказание точки
контакта, запрет волея и дистанции тут ни при чём (в 100 % случаев ИИ был в 0.9 м от мяча).
Чаще всего страдал слабый/усталый ИИ и широкие укороченные (мяч у боковой, ИИ догоняет по диагонали).

## Исправление
`OpponentAI._slow_ball_in_reach`: медленный (< 3 м/с по земле), уже отскочивший мяч на высоте 0.2…1.5 м
в зоне досягаемости бьётся, когда он у плоскости удара или не дальше 0.4 м перед ней. Обычные мячи и
подачи идут прежним путём (пересечение плоскости). Тест `ai_test.test_drop_return` — микро-симуляция
с настоящими `Ball`, `Athlete`, `OpponentAI`: 300 укороченных с задней линии с сильным штопором.

## Метрики (300 очков, `--bot-drop=0.4`, сид 7)
«Бьёт» — доля укороченных игрока, на которые ИИ ответил ударом; «добежал, не ударил» — жалоба;
«очки с укороченным за игроком» — доля очков с укороченным, выигранных игроком.

| Сценарий | Бьёт до → после | Добежал, не ударил до → после | Очки с укороченным за игроком до → после |
|---|---|---|---|
| Рублёв, ур. 8, бот 0.035 | 98 → 97 % | 0 → 0 % | 11 → 18 % |
| Джумхур, ур. 8, бот 0.035 | 99 → 98 % | 0 → 0 % | 15 → 24 % |
| Джумхур, новичок 0.07 | 78 → 75 % | 5 → 0 % | 37 → 24 % |
| Басилашвили, новичок | 87 → 85 % | 0 → 0 % | 21 → 20 % |
| Зверев, новичок | 83 → 80 % | 0 → 0 % | 17 → 14 % |
| Джокович, новичок | 84 → 81 % | 0 → 0 % | 9 → 8 % |
| Рублёв, ур. 8, ИИ-навык 0 (слабый, усталый) | 85 → 97 % | 12 → 0 % | 45 → 29 % |
| Рублёв, ур. 0, бот 0.035 | 92 → 87 % | 0 → 1 % | 16 → 14 % |

Остаток «не бьёт» — укороченные, ушедшие в аут/сетку у самого игрока («own error»). Тест (микро-симуляция):
добежал и не ударил было 28 из 300 (сильный ИИ) и 70 из 300 (слабая «Сетка» и скорость), стало 0 и 0.
ИИ по-прежнему сам играет укороченные по D-3 (`VARIETY_DROP`, метрика `cpu shots … drops` не изменилась: 0.7 %).
