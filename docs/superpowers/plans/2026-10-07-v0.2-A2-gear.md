# A-2 Вещи и выносливость соперника — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** три слота (ракетка, кроссовки, напульсник) и сумка на 6, пять редкостей с мифической,
25 вещей с эффектами без меток мяча, вещи у соперника и лут с него; выносливость соперника
как «здоровье» с полоской, осколками и цифрами урона, которая делает его медленнее и
ошибчивее.

**Architecture:** чистые классы — `Items` (каталог), `Gear` (генератор обычных/редких для
трёх слотов, пять редкостей), `RunEffects` (шина: триггер → условие → действия),
`OppStamina` (модель урона и отдыха), `Tournament` (equip, bag, lineup.gear, лут).
`RunHub` слушает `GameEvents`, кормит `RunEffects` и `OppStamina`, применяет действия к
Main (своя STA, золото забега, `Skills.gear`, `ai.speed_mult`, `Tuning.ai_skill`) и рисует
`OppStaminaView`. Экран сумки — `scripts/ui/screens/run_bag.gd`.

**Tech Stack:** Godot 4.4.1, GDScript, headless SceneTree-тесты.

Спецификация: [2026-10-07-v0.2-roguelike-design.md](../specs/2026-10-07-v0.2-roguelike-design.md), раздел 3.

## Global Constraints

- Godot только 4.4.1; логика через `GameEvents`; в `main.gd`/`tournament_ui.gd` — крючки по 1–3 строки.
- Свои файлы: `scripts/run/*`, `scripts/ui/screens/run_*.gd`, `scripts/gear.gd`, `scripts/rewards.gd`,
  `scripts/tournament.gd`, `tests/roguelike_test.gd`, `tools/run_shots.gd`.
- Сохранения: только новые поля/секции; старое поле забега `racket` читается и переезжает в `equip.racket`.
- Без меток мяча (Огонь/Лёд/Тяжесть) — решение владельца.
- Всё рогаликовое — только в турнире; в тренировке нет полоски соперника.
- Python на Windows: `newline=''`, окончания строк файла сохранять.

## Решения по коду

- **Вещь** (сохраняемая): `{slot, rarity, name, mods, lines}` + `id` у уникальных из каталога.
  Триггеры и стиль берутся из `Items.find(id)` при игре (сейвы маленькие, баланс правится данными).
- **`Tournament.racket`** остаётся свойством-обёрткой над `equip["racket"]` (get/set): старые
  места (`_set_opponent_mods`, сетка, награды, бот) работают, старый сейв с `racket` мигрирует сам.
- **`lineup[i]`**: `{mods, gear: {racket, shoes, band}, racket}`; `racket` = `gear.racket` (для вида
  ракетки соперника и «Трофея»). Сила от вещей — в `modifier_value("skill")`: +0.01 × редкость.
- **Лут** (`record_match`): каждая вещь соперника — шанс 30/20/12/6/3% по редкости. Лучшая
  эпик+ → `pending_loot` («Трофей», как сейчас); остальные выпавшие → сумка (`t.new_items`
  для итога). Сумка полна — лишнее продаётся автоматически (`t.auto_sold`).
- **Цены продажи** 3/6/12/25/50; мифическая — максимум одна на забег (`t.mythic_rolled`).
- **Эффекты (`RunEffects`)** — данные вещи: `mods`, `style` ({trick: ×, "all": ×}),
  `rules` (`cannon_kmh`, `dive_free`, `run_dmg`, `second_wind`), `cond_mods`
  ([{if: {tiebreak: true}, mods}]), `triggers` ([{on, if, do: [[prim, args…]]}]).
  Примитивы: `opp_stamina(n)`, `self_stamina(f)`, `money(n)`, `temp_mod(key|"pace"|"all", v)` (до
  конца очка), `run_mod("all", v)` (до конца забега, `t.run_mods`), `point_style(×)`.
  Условия: `type`, `label`, `every_n`, `streak`, `reason`.
- **`OppStamina`**: 0…100. Урон за мяч: `метры × 0.6 × run_dmg + max(0, км/ч − 90) × 0.05`,
  `× 1.5` за PERFECT игрока. Отдых: очко +6, смена сторон +20, сет +40. Усталость ниже 40:
  `t = (40 − v) / 40`; ИИ: `speed × (1 − 0.3 t)`, `skill − 0.12 t`. Коэффициенты подбирает бот.
- **Смена сторон/сет/брейк** — после `point` хаб откладывает проверку (`call_deferred`) и
  сравнивает `scoreboard.games/sets` до и после.

## Задачи

### Task 1: Gear — пять редкостей и три слота
Files: `scripts/gear.gd`, test `test_gear_slots`.
- `RARITIES` += mythic; цвета из `UiTheme.RARITY`; `MYTHIC := 4`.
- `AFFIXES_BY_SLOT := {racket: [...текущие удары], shoes: [run_speed, move_penalty, stamina_pool,
  stamina_drain, stamina_rest], band: [окна пяти ударов, serve_pace]}`.
- `Gear.roll(rarity, rng, slot := "racket")`: обычная/редкая — генератор (имя по роду слота:
  «Обычная ракетка …», «Редкие кроссовки …», «Обычный напульсник …»), с шансом 35% —
  уникальная из каталога той же редкости; эпик+ — `Items.roll(slot, rarity, rng)`.
- `Gear.price(item)`, `Gear.slot_name(slot)`.
- Тест: 3 слота × 5 редкостей → правильный `slot`/`rarity`, ключи модов из пула слота,
  эпик+ имеет `id` из каталога, цены 3/6/12/25/50, старый вызов `roll(EPIC, rng)` → ракетка.

### Task 2: Items — каталог 25 вещей
Files: `scripts/run/items.gd`, test `test_items_catalog`.
- `Items.LIST` — 25 записей из спецификации 3.3 (поля как выше), `find(id)`, `roll(slot, rarity, rng)`,
  `instance(entry) -> item`, `describe(item) -> String` (эффект строкой + строки модов).
- Тест: 25 вещей, по каждому слоту есть все редкости от редкой до мифической, у эпик+ есть
  `triggers`/`style`/`rules`/`cond_mods` (не только моды), id уникальны, `describe` не пуст.

### Task 3: RunEffects — шина эффектов
Files: `scripts/run/run_effects.gd`, test `test_run_effects`.
- `RunEffects.new(equip: Dictionary, run_mods := {})`; `mods(state := {}) -> Dictionary`
  (моды вещей + `cond_mods` при `state.tiebreak` + временные + `run_mods`); `style_boosts()`;
  `rule(name) -> float` (0 = нет); `fire(event, ctx) -> Array` действий (с учётом `every_n`
  по `ctx.rally_n`, `streak` PERFECT подряд, внутренние счётчики); `end_point()` чистит
  временные моды и множитель очка; `point_style() -> float`.
- Тест: Кувалда даёт `opp_stamina 8` только на 4-м и 8-м ударе; Солнце — `opp_stamina 6` на
  PERFECT и `30` + `point_style 2` на третьем подряд, GOOD сбрасывает серию; Холодный
  компресс меняет `mods()` только при `tiebreak`; Берсерк копит +3% силы за удар и
  `end_point` сбрасывает; Корона даёт `run_mod`; Золотая рука → `style_boosts().all == 1.5`;
  Пушечная рама → `rule("cannon_kmh") == 190`.

### Task 4: OppStamina — модель
Files: `scripts/run/opp_stamina.gd`, test `test_opp_stamina`.
- `value`, `damage(n) -> float`, `shot_damage(meters, kmh, perfect, run_mult) -> float`,
  `rest(kind)`, `tired() -> float`, `speed_mult() -> float`, `skill_penalty() -> float`.
- Тест: формула (5 м, 150 км/ч, PERFECT → (3 + 3) × 1.5 = 9), не ниже 0 и не выше 100,
  отдых по видам, `tired()` 0 выше 40 и 1 на нуле, множители ИИ на краях.

### Task 5: Tournament — снаряжение, сумка, вещи соперника, лут
Files: `scripts/tournament.gd`, `scripts/rewards.gd` (карточка вещи: слот любой), test
`test_tournament_gear`.
- `equip`, `bag`, `new_items`, `auto_sold`, `run_mods`, `mythic_rolled`; `racket` — get/set
  над `equip.racket`; `SAVED` += новые поля.
- `roll_lineup`: `gear` на три слота с шансами 62/27/8/2.5/0.5% (+ сдвиг: круг × 4% вверх,
  бонусы модификаторов и босса как сейчас), `racket = gear.racket`.
- `modifier_value("skill")` += 0.01 × сумма редкостей вещей соперника.
- `record_match` → `_roll_drops(r)`; `take_loot(equip)` кладёт в слот вещи, старую — в сумку.
- `equip_from_bag(i)`, `sell_from_bag(i) -> int`, `add_to_bag(item)` (полная — автопродажа).
- `take_reward` для вещи: пустой слот — надеть, иначе в сумку.
- Тест: миграция старого словаря с `racket`; сохранение/загрузка equip+bag; лут по шансам
  на 20 000 бросков (в допуске ±1.5 п.п.); полная сумка продаёт; надеть меняет местами;
  мифическая не больше одной за забег.

### Task 6: RunHub — эффекты и выносливость соперника в матче
Files: `scripts/run/run_hub.gd`, `scripts/run/opp_stamina_view.gd`.
- `match_started` (турнир): `effects = RunEffects.new(t.equip, t.run_mods)`, `opp = OppStamina.new()`,
  `boosts = effects.style_boosts()` (+ `cannon_kmh`), базовые `ai.speed_mult`, `Tuning.ai_skill`
  запомнить, `Skills.gear = effects.mods()`.
- Физкадр в розыгрыше: копить метры соперника; ИИ: `ai.speed_mult = base × opp.speed_mult()`,
  `Tuning.ai_skill = base − opp.skill_penalty()`; `cpu.tired` между очками при усталости.
- `shot(CPU)`: урон за мяч; `player_stroke`: `on_hit`/`on_perfect`/`on_dive`(+`dive_free`
  возврат STA); `point`: `on_ace`, `on_point_won(tricks)`, `on_point_lost`, недобежавший
  соперник получает урон за метры; отложенно — `on_game_won`/`on_break`/смена сторон/сет:
  отдых соперника (кроме `second_wind`), `on_change_ends`.
- Действия: `opp_stamina` → `opp.damage` + вид; `self_stamina` → `main.stamina`;
  `money` → `t.gold`; `run_mod` → `t.run_mods`; `point_style` → множитель очка.
- `match_finished`: вернуть `ai.speed_mult`, `Tuning.ai_skill`, `cpu.tired`; бот печатает
  `OPP STA: min %d, damage %d`.
- `OppStaminaView`: полоска над соперником (проекция камеры), откол куска, белый след 0.4 с,
  цифры «−12» из груди (белый — бег, жёлтый — тяжёлый мяч, оранжевый — вещи; ≥ 25 крупнее),
  пул 8, пульс ниже 40%. Тест: `test_opp_view` (пул не растёт больше 8, цвет по виду).

### Task 7: Экран сумки и крючки экранов
Files: `scripts/ui/screens/run_bag.gd`, хуки `tournament_ui.gd` (`show_bracket`: кнопка
«Сумка · N» и подсказка вещей вместо названия ракетки; `show_loot`: сравнение со слотом
вещи; `show_result`: «В сумку: …»), `main.gd` (`_on_ui`: `bag`, `bag_item`, `equip`, `sell`).
- Сумка: три карточки надетого, ниже сумка (GameCard с редкостью); тап — экран вещи:
  карточка, сравнение с надетой (строки модов, ↑/↓), «Надеть», «Продать +N», «Назад».
- Снимки `tools/run_shots.gd`: сетка, сумка, вещь, лут — 720×1564 и 1480.
