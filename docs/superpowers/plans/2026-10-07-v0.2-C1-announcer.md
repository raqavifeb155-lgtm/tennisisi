# C-1 «Диктор» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** все надписи в матче живут в одной схеме: ничего не вылезает за экран и не
налезает друг на друга, выкрики — по словарю, трофей — карточкой (UI_FLOW_TZ 4.6, 5, P0-1,
P1-1, P1-2, P2-1, P2-2, P2-10).

**Architecture:** новый `HudAnnouncer` (Control на слое HUD) держит колонку объявлений
(`VBoxContainer` под счётом), центр для больших моментов и строку-подсказку; позиции по
`y` не пишутся руками. Чистые функции — `UiText.fit_size` (вписывание кегля) и `Calls`
(словарь выкриков) — тестируются без отрисовки. `Hud` и `Main` только вызывают его:
крючки отдельными коммитами.

**Tech Stack:** Godot 4.4.1, GDScript, UiTheme (Russo One + Golos Text).

## Global Constraints

- Godot только 4.4.1: `C:\Users\pipij\.cache\godot-4.4.1\Godot_v4.4.1-stable_win64_console.exe`.
- Одна строка — один язык. Выкрики — английские заглавные; подсказки, прокачка, итог —
  по-русски, «км/ч» (UI_FLOW_TZ 5.6).
- Минимальный кегль HUD — 24 px; вердикт 56 px, вниз до 40, потом перенос, ≤ 2 строки;
  ширина колонки 640.
- Шрифты и цвета — только `UiTheme`. Время — реальное (`set_ignore_time_scale`).
- Крючки в `hud.gd`, `main.gd`, `opponents.gd`, `timing_ring.gd` — отдельные маленькие
  коммиты, не вместе с новыми файлами (просьба сборщика). Файлы потока A
  (`scripts/run/*`) не трогать: для плашки стиля — API `reserve()` и сообщение A.
- LF в файлах.

### Task 1: вписывание текста `UiText.fit_size`

**Files:** Create `scripts/ui/ui_text.gd`, `tests/ui_test.gd`.

**Produces:** `static func fit_size(font: Font, text: String, width: float, max_size: int, min_size: int) -> int`
— самый крупный кегль ≤ `max_size`, при котором **каждая** строка `text` (по `\n`)
укладывается в `width`; если не влезает и на `min_size` — возвращает `min_size`
(дальше перенос делает Label). `static func fits(font, text, width, size) -> bool`.

- [ ] Step 1: тест

```gdscript
func test_fit_size() -> void:
	print("fit size")
	var f := UiTheme.display()
	check(UiText.fit_size(f, "ACE!", 640.0, 56, 40) == 56, "a short call keeps 56")
	var long_name := "BASILASHVILI DOUBLE FAULT"
	var s := UiText.fit_size(f, long_name, 640.0, 56, 40)
	check(s < 56 and s >= 40, "a long call shrinks: %d" % s)
	check(UiText.fits(f, long_name, 640.0, s) or s == 40, "and fits, or stops at the floor")
	check(UiText.fit_size(f, "ГЕЙМ\nБАСИЛАШВИЛИ ДВОЙНАЯ ОШИБКА ПОДАЧИ", 640.0, 56, 40) == 40, "the widest line decides")
```

- [ ] Step 2: `"$G" --headless --path . -s tests/ui_test.gd` → FAIL (нет `UiText`).
- [ ] Step 3: реализация — цикл от `max_size` вниз с шагом 2, `font.get_string_size(line, HORIZONTAL_ALIGNMENT_LEFT, -1, size).x <= width` для всех строк.
- [ ] Step 4: PASS. Step 5: коммит «C-1: UiText.fit_size».

### Task 2: словарь выкриков `Calls` и `short_en`

**Files:** Create `scripts/ui/calls.gd`; Modify `scripts/opponents.gd` (крючок, отдельный коммит); test в `tests/ui_test.gd`.

  `"%s OUT" % cpu`, `"%s NET"`, `"WINNER!"`, `"ACE!"`, `"%s DOUBLE FAULT"`. Проиграл:

- `Opponents.ROSTER[i]["short_en"]`: DZUMHUR, BASILASHVILI, RUBLEV, ZVEREV, DJOKOVIC.

- [ ] Step 1: тест

```gdscript
func test_calls() -> void:
	print("calls")
	check(Calls.point(true, "OUT", "RUBLEV") == "RUBLEV OUT", "their out")
	check(Calls.point(false, "ACE", "RUBLEV") == "RUBLEV ACE", "their ace")

		check(latin.search(String(o.get("short_en", ""))) != null, "latin short name: %s" % o.get("short_en", "-"))
```

### Task 3: `HudAnnouncer` — колонка, вердикт, тосты, `reserve`

**Files:** Create `scripts/ui/hud_announcer.gd`; test в `tests/ui_test.gd`.

**Consumes:** `UiText.fit_size`.
**Produces** (`class_name HudAnnouncer extends Control`, full rect, `MOUSE_FILTER_IGNORE`):
- `const COLUMN_TOP := 130.0`, `const WIDTH := 640.0`, `const CALL_MAX := 56`, `const CALL_MIN := 40`, `const SUB := 28`, `const TOAST := 28`, `const MAX_TOASTS := 2`.
- `set_safe_area(top: float, bottom: float) -> void` — колонка с `COLUMN_TOP + top`.
- `call_point(main: String, sub: String, color: Color) -> void` — вердикт; новый заменяет
  старый (он всегда первый в колонке). Плашка `SURFACE` 0.85, главная строка Russo One
  `fit_size(..., WIDTH - 48, 56, 40)`, при `40` и всё ещё шире — `autowrap` + `max_lines_visible = 2`.
  Держится 1.1 с, уходит 0.3 с.
- `toast(text: String, key := "", gold_frame := false) -> void` — прокачка: видно ≤ 2,
  остальные ждут; тост с тем же `key` обновляет текст видимого, а не добавляется.
  Один кегль 28 (перенос, не ужатие). 1.6 с + 0.4 с.
- `reserve(height: float, seconds: float) -> float` — пустое место в колонке после
  вердикта (для VAR и плашки стиля A); возвращает глобальный `y` его верха.
- `column_items() -> Array[Control]` (для тестов), `finish_now()` — убрать всё сразу.

- [ ] Step 1: тест

```gdscript
func test_announcer_column() -> void:
	print("announcer column")
	var a := HudAnnouncer.new()
	a.size = Vector2(720, 1564)
	root.add_child(a)
	a.set_safe_area(180.0, 60.0)
	a.call_point("BASILASHVILI DOUBLE FAULT", "GAME · YOU", UiTheme.WIN)
	a.call_point("ACE!", "", UiTheme.WIN)
	check(a.column_items().size() == 1, "a new call replaces the old one")
	for i in 4:
		a.toast("НОГИ %d" % (3 + i), "feet")
	a.toast("ФОРХЕНД 5", "forehand")
	a.toast("ПОДАЧА 2", "serve")
	check(a.column_items().size() == 1 + HudAnnouncer.MAX_TOASTS, "two toasts at most: %d" % a.column_items().size())
	var y := a.reserve(190.0, 2.6)
	check(y >= 180.0 + HudAnnouncer.COLUMN_TOP, "a reserved slot sits in the column, under the safe area")
	a.queue_free()
```

Плюс тест раскладки (после `await process_frame` в отдельном `SceneTree`-проходе не
нужен: колонка — `VBoxContainer`, проверяем, что прямоугольники элементов не
пересекаются, через `get_combined_minimum_size()` и порядок детей).
