# Клуб H1: ходибельный клуб — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Главное меню становится клубом-миром уровня 0: герой ходит по клубу, у мест круги и одна кнопка, быстрый переход, все прежние экраны открываются из мест, от запуска до матча 2 тапа.

**Architecture:** Узел `Club` (как `RunHub`) создаётся в `Main` и включается, когда `Main` показывает меню: ставит локацию `club` (`ClubWorld extends Scenery`), свою камеру, свой интерфейс (`ClubHud`), ведёт героя (`player`) и тренера (`cpu` в образе тренера). В `main.gd` — только крючки. Данные мест (`ClubPlaces`) и ходьба (`ClubWalk`) — чистые классы без сцены, их проверяют тесты headless.

**Tech Stack:** Godot 4.4.1, GDScript, сцена из кода, рендер совместимости (WebGL2).
