## Слои (одно направление зависимостей: данные -> логика -> живой матч -> экраны)

## Крючки (отдельными маленькими коммитами)
- `main.gd`: поле `spectate` (Node или null) + 3 строки: `_autoplay_tick` отдаёт тик боту юниора, `_gain_xp` молчит,
  `_stop_match` зовёт откат; `me_label` вместо жёсткого «ВЫ»; ветка `--junior-duel` в `_ready`.
- `game_camera.gd`: `booth_wide` работает и в режиме «Матч» (флаг `spectate`), `booth_flip` для стороны будки.
- `club.gd`: создать `JuniorWatch`, маршрут `club_match*` в `ui_action`, кнопка/значок будки.
- `club_places.gd`: место `booth` открыто после первого забега, действие `club_booth` (данные).

## Порядок
1. Сим + установки + тест (чистая логика). 2. Живой бот + дуэль-инструмент. 3. Калибровка уровней (честный бой
равных), затем силы установок (+10…15 / −5…10), затем коэффициенты `junior_sim` по живым (расхождение <= 3 п.п.).
4. Расписание/результат/награды. 5. Живой режим, камеры, советы. 6. Экраны, клуб, снимки, overlay_probe, FPS.

## Решения (в отчёт)
- Соперник — «юниор острова»: статы около статов ученика со сдвигом тира (честный бой 35–65%), а не профи топ-100.
- Автопилот (советы выключены): тренер выбирает вариант со второй по силе `fit` (половина выгоды).
- Профиль героя (`Skills`, `lifetime_xp`, `mods_layer`, `autoplay`, `_bot_sd`) прячется на время матча и возвращается в `on_stop`.
