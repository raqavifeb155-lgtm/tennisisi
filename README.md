# Tennis Roguelike — прототип

Мобильный 3D-теннис на физике, поверх которого позже будет roguelike.
Главный принцип из дизайн-документа: **BETTER FEEL > MORE FEATURES**.

Движок: **Godot 4.4** (GDScript). Проект целиком текстовый: сцена собирается из кода,
поэтому его можно разрабатывать и проверять без редактора.

## Как играть

Достаточно одного пальца, телефон вертикально.

- **Тап по корту:** игрок бежит туда. Если держать палец, игрок бежит за ним. Пока ты никуда не тапнул, игрок сам подстраивается под мяч.
- **Свайп в любом месте экрана:** удар. Мяч летит **по линии от игрока** в ту сторону, куда ты провёл. Глубину игра выбирает сама, с запасом внутри корта. Быстрый свайп даёт сильный удар, медленный — мягкий.
- **Кольцо тайминга (как в Top Spin):** когда мяч подлетает, кольцо сжимается к кругу в точке удара. Свайпни, когда оно совпадёт с кругом, и будет PERFECT (кольцо станет золотым). При идеальном ударе мяч почти никогда не уходит в аут. Ошибаются ранние и поздние удары.
- Пока ведёшь палец, пунктир и жёлтый круг показывают, куда полетит мяч. После удара белая точка показывает, куда он упал на самом деле.
- **Подача:** тап подбрасывает мяч, потом свайп в сторону диагонального квадрата, когда кольцо вокруг мяча сожмётся. Две попытки, LET при касании сетки.
- Кнопки **TOPSPIN / FLAT / SLICE** сверху выбирают вращение (на подаче: кик / плоская / резаная).
- **НАСТР** (справа вверху): ползунки, которыми настраивается ощущение игры прямо на телефоне.

На компьютере: клик — бежать, протяжка мышью — удар, WASD — бег.

## Что уже есть (Фазы 1–2 дизайн-документа)

| Система | Где |
|---|---|
| Физика мяча: гравитация, сопротивление воздуха, эффект Магнуса, отскок с трением и обменом вращения, сетка | `scripts/ball_physics.gd` |
| Решатель удара: намерение (цель, сила, вращение) превращается в реальный вылет мяча | `scripts/shot_solver.gd` |
| Качество удара = тайминг × позиция × движение; ранний удар тянет мяч, поздний толкает | `scripts/main.gd` |
| Управление: тап — бег, свайп — удар по линии от игрока, кольцо тайминга | `scripts/touch_input.gd`, `scripts/timing_ring.gd`, `scripts/main.gd` |
| Slow-motion окно, hit-stop, тряска камеры, вибрация, звук | `scripts/main.gd`, `scripts/game_camera.gd` |
| Игрок: инерция, ускорение/торможение, split-step, процедурный замах ракеткой к мячу | `scripts/athlete.gd` |
| Соперник: предсказание мяча, выбор позиции, тактика (бить в открытый угол, защищаться, когда растянут) | `scripts/opponent_ai.gd` |
| Правила розыгрыша: аут, сетка, два отскока, длина розыгрыша | `scripts/main.gd` |
| Подача по правилам: стороны «ровно»/«больше», диагональный квадрат, FAULT / DOUBLE FAULT / LET / ACE | `scripts/main.gd` |
| Теннисный счёт: 15/30/40, DEUCE, AD, геймы, смена подающего | `scripts/tennis_score.gd` |
| Debug-панель и все параметры ощущений | `scripts/hud.gd`, `scripts/tuning.gd` |
| Звуки (сгенерированы процедурно, без чужих ассетов) | `tools/gen_sfx.py` → `assets/sfx/` |

## Проверки

```bash
# физические тесты (отскок по нормам ITF, topspin/slice, точность решателя, сетка)
godot --headless --path . -s tests/run_tests.gd

# бот играет 40 очков против CPU и печатает статистику розыгрышей
godot --headless --path . --fixed-fps 60 -- --autoplay --points=40

# сквозной тест управления: настоящие тапы и свайпы (подача, удары, бег тапом)
godot --headless --path . --fixed-fps 60 -s tests/input_test.gd

# веб-сборка в build/web (скачивает Godot и шаблоны при первом запуске)
tools/build_web.sh
```

`build/web` закоммичен специально: Vercel раздаёт его как статический сайт без шага сборки.
