# «Матчбол» на своём сервере (Hostkey) — Telegram Mini App

Игра — это набор файлов, который сервер просто раздаёт по HTTPS: сама она работает на
телефоне игрока. Поэтому серверу хватит самого маленького VPS.

## 1. Сервер

1. В Hostkey закажите VPS с **Ubuntu 22.04 или 24.04** (подойдёт и Debian 12).
   Хватит 1 vCPU, 1–2 ГБ памяти и 10+ ГБ диска.
2. Hostkey пришлёт **IP-адрес** и **пароль root** (письмо или личный кабинет).
3. Если в панели Hostkey включён файрвол, откройте входящие порты **22, 80 и 443**.

Свой домен не обязателен: без него адрес будет вида `https://95-216-1-2.sslip.io/`
(бесплатный сертификат выдаётся на этот адрес автоматически). Если домен есть,
заранее сделайте A-запись, указывающую на IP сервера.

## 2. Загрузить архив на сервер

Замените `IP` на адрес сервера.

**Windows** (PowerShell, всё уже встроено):
```powershell
scp .\tennis-hostkey.zip root@IP:/root/
ssh root@IP
```
Или программой WinSCP: перетащите `tennis-hostkey.zip` в папку `/root`.

**macOS / Linux:**
```bash
scp tennis-hostkey.zip root@IP:/root/
ssh root@IP
```

## 3. Установить (один раз)

На сервере:
```bash
apt-get update && apt-get install -y unzip
unzip -o tennis-hostkey.zip
sudo bash tennis/install.sh                    # без домена
# или: sudo bash tennis/install.sh game.мой-домен.ru
```

Через 1–2 минуты скрипт напишет адрес, например `Done: https://95-216-1-2.sslip.io/`.
Откройте его в браузере телефона: игра должна запуститься.

Скрипт ставит nginx и бесплатный HTTPS-сертификат Let's Encrypt (продлевается сам).
Если порты 80/443 уже заняты чем-то другим (например, VPN), он остановится и ничего не
тронет.

## 4. Подключить к боту

@BotFather → `/mybots` → ваш бот → **Bot Settings**:

- **Configure Mini App** (или Mini Apps → Main App) → включить → вставить адрес;
- **Menu Button** → вставить тот же адрес, текст кнопки: «Играть».

Если бота ещё нет: в @BotFather команда `/newbot`, затем шаги выше.

## 5. Обновить игру (новая версия)

Загрузите новый `tennis-hostkey.zip` так же, как в шаге 2, и на сервере:
```bash
unzip -o tennis-hostkey.zip && sudo bash tennis/install.sh
```
Скрипт сам поймёт, что игра уже стоит, и только заменит файлы. Игроки получат новую
версию при следующем открытии.

## Если что-то не так

| Что видно | Что сделать |
|---|---|
| `Port 80 is used by ...` | Порт занят другой программой. Нужен отдельный сервер или домен. |
| certbot: `Timeout during connect` | Порты 80/443 закрыты файрволом в панели Hostkey — откройте их. Для своего домена проверьте, что A-запись указывает на сервер. |
| В браузере открывается, в Telegram — белый экран | Адрес должен начинаться с `https://`. Перезапустите Telegram. |
| Долго грузится в первый раз | Игра весит ~10 МБ (сжато); дальше браузер берёт её из кэша. |

Проверить, что сервер отвечает: `curl -I https://ВАШ-АДРЕС/` — должно быть `200`.
